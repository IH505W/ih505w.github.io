Privacy policy

This policy describes the initial Google integration and the intended data practices of n8n Personal Automation, a private project operated by its owner, IH505W.

Google data accessed

The owner explicitly authorizes connections through Google OAuth. The Gmail connection currently requests read-only access to messages and settings. Workflows may retrieve message identifiers, headers, senders, recipients, subjects, snippets, and message bodies when needed for an enabled feature. Attachments are not intentionally downloaded by the initial connection test.

The Calendar connection requests free/busy access. It retrieves busy time intervals for the calendars and time windows selected in a workflow. It does not request permission to read event titles or descriptions, or to create, change, or delete events.

OAuth credentials and tokens are used to maintain these authorized connections. Future features requiring broader access will require an updated policy and Google consent.

How data is used

Currently, the integration retrieves messages and availability for connection testing. Planned workflows will use email content for local analysis, categorization, reply suggestions, and owner notifications, and availability information for scheduling assistance. Replies are intended to be reviewed and sent manually by the owner.

Google user data is not used for advertising, sold, or used to train a general-purpose AI model. Google data will be used only to provide the functionality described in this policy. Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Processing, storage, and sharing

Retrieved Google data is processed in the owner's private n8n installation. Planned AI analysis will run on the owner's locally hosted Ollama server rather than a cloud AI service. Message data may be retained in local workflow execution records depending on n8n's execution-saving settings. Credentials and tokens are stored by the private n8n installation.

Google hosts the source mailbox and calendars and processes API requests according to Google's own policies. Email content, calendar data, and OAuth credentials are not uploaded to this public website or its GitHub repository. If notifications or other future integrations would share Google data with an additional service, the owner will document that service and sharing here before enabling it.

Retention and deletion

Local execution records and other workflow-generated data remain until deleted by the owner or removed by configured retention rules. This initial setup has not established a fixed retention period. Copies included in backups may remain until those backups are removed or expire.

The owner can stop workflows, delete stored execution records and generated files, and remove credentials from n8n. Google authorization can be revoked through the account's third-party connections settings. Revocation prevents further authorized access but does not automatically delete data already stored locally. Deleting local copies does not delete the original Gmail messages or Calendar events.

Public website

This informational site uses no application analytics, tracking scripts, or email submission forms. Its hosting provider, GitHub Pages, may log visitor IP addresses for security purposes. See the GitHub Privacy Statement for the hosting provider's practices.

Changes and contact

This policy will be updated before data access or processing practices change. The support email displayed on the Google consent screen is the contact address for this private integration.
