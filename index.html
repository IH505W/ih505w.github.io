Personal automation,
locally hosted.

A private assistant designed to help its owner review email, prepare replies, and check calendar availability using a locally hosted AI model.

Current capabilities

The initial integration can read messages from the owner's authorized Gmail account and check busy times in the owner's authorized Google Calendar. Calendar access is limited to availability; event titles and descriptions are not requested.

Email classification, reply drafting, notifications, and automated background workflows are planned features. Reply drafts are intended for the owner to review and send manually in Gmail.

Why Google access is requested

Gmail read access provides the message information needed for email review and future analysis. Calendar availability access provides busy intervals needed to identify scheduling conflicts. The currently configured connections do not authorize sending email, deleting messages, or changing calendar events.

If a future feature requires additional permissions, those permissions will be requested through Google consent and documented here before that feature is enabled.

Where the assistant runs

The assistant runs in the owner's private n8n installation. The planned AI processing uses the owner's local Ollama server. This public website contains information about the project and its data practices. It provides no access to the assistant, email messages, calendars, or credentials.

Personal use and contact

This integration is intended only for its owner. It has no public signup or commercial service. The owner is identified on GitHub as IH505W. The support email displayed on the Google consent screen is the contact address for the integration.

Read the privacy policy for details about Google data access and storage, and the terms of use for the intended use of this project.
