A private assistant designed to help its owner review email, prepare replies, and check calendar availability using a locally hosted AI model.

Capabilities

The integration reads messages from the owner's authorized Gmail account and uses a local model to summarize, categorize, assess reply needs, and prepare suggested reply text. It can also check busy times in the owner's authorized Google Calendar. Calendar access is limited to availability; event titles and descriptions are not requested.

An optional, separately authorized draft-writing connection saves suggested replies as Gmail drafts for the owner to review and send manually. Features are being configured and tested in stages. Background processing and owner notifications are enabled only through the owner's configured workflows.

Why Google access is requested

Gmail read-only access provides message information for review and local analysis. Calendar free/busy access provides intervals needed to identify scheduling conflicts. A separate optional Gmail connection requests gmail.compose to save drafts.

Google's compose permission also permits sending email and managing drafts, including deleting drafts. The automated workflow uses that connection only for configured draft operations; it does not automatically send email or delete drafts. The AI model receives email content for text generation and has no Gmail credentials or Gmail action tools. The read-only connection remains responsible for inbox retrieval.

Additional permissions will be requested through Google consent and documented here before related features are enabled.

Where the assistant runs

The assistant runs in the owner's private n8n installation. AI analysis and reply preparation use the owner's local Ollama server. This public website contains information about the project and its data practices. It provides no access to the assistant, email messages, calendars, or credentials.

Personal use and contact

This integration is intended only for its owner. It has no public signup or commercial service. The owner is identified on GitHub as IH505W. The support email displayed on the Google consent screen is the contact address for the integration.

Read the privacy policy for details about Google data access and storage, and the terms of use for the intended use of this project.
